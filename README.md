## About me

I'm **Apinan Woratrakun**, a full-stack engineer working with **Next.js, TypeScript, Prisma, and PostgreSQL**. My interests connect interface design with the systems behind it: how people use an application, how its data flows, and how it fits into everyday business workflows.

I enjoy clean UI, carefully considered dark themes, and experiences that feel natural to Thai users. I also work with **LINE Bot SDK and Loyverse POS**, and explore how AI agents can help turn repetitive tasks into structured, testable workflows.

> Clear interfaces. Connected systems. Practical automation.

## What I focus on

| Focus | What interests me |
| :--- | :--- |
| **Web engineering** | Connecting React and Next.js interfaces with application logic and data. |
| **Interface design** | Clear layouts, deliberate visual details, and language-aware experiences for Thai users. |
| **Business integrations** | Bringing web applications, LINE, and POS tools into connected workflows. |
| **AI & automation** | Exploring agent-assisted workflows with dry-run checks and traceable execution. |
